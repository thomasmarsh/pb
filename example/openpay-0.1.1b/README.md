# OpenPay — PowerBuilder Source Corpus

This directory contains the exported PowerBuilder source files of the **OpenPay**
open-source payroll application, used here as a parser regression corpus.

The original project is an open-source payroll program written in PowerBuilder,
designed to support the payroll legislation of any country. It was developed primarily
for Greek payroll requirements and distributed in both English and Greek.
